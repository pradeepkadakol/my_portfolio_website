# Portfolio Website

A simple personal portfolio website built with plain HTML and CSS.

## Project files

- `p1.html` — main page markup
- `assets/studio.css` — styling and layout
- `assets/pk-mark.svg` — logo mark

## Preview locally

Open `p1.html` in a browser, or run a small local server from the project folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Notes

This portfolio is lightweight and does not require a framework or build step.
